# TiffinOS – Family Edition

> **Run Your Tiffin Business. Without the Daily Chaos.**  
> A professional, production-quality, responsive web application purpose-built for independent tiffin services.

---

## 🍽️ Overview

TiffinOS replaces manual registers, loose paper sheets, and messy spreadsheets with a centralized, reliable operating system for tiffin business owners.

### Key Capabilities:
- **Customer Management**: Maintain recurring weekly meal subscriptions with individual lunch and dinner pricing.
- **Daily Meal Dispatch**: Mobile-first dispatch terminal to pack and dispatch tiffins with one tap and duplicate protection.
- **Dispatched-Only Billing**: Generate monthly customer invoices calculated exclusively from meals actually delivered.
- **Expense Tracking**: Log groceries, vegetables, gas, packaging, and operating expenses.
- **Financial Analytics**: Real-time revenue vs. expenses, operating profit, and customer balance tracking in Indian Rupee (INR ₹).

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Start development server
```bash
npm run dev
```

Visit:
- Public Landing Page: [http://localhost:5173/](http://localhost:5173/)
- Design System Showcase: [http://localhost:5173/design-system](http://localhost:5173/design-system)
- Business Dashboard: [http://localhost:5173/app/dashboard](http://localhost:5173/app/dashboard)

### 3. Build for production
```bash
npm run build
```
